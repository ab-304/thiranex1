# Password Strength Analyzer

## Task Description
Developed a Password Strength Analyzer that evaluates the strength of user-entered passwords based on security criteria such as length, uppercase letters, lowercase letters, numbers, and special characters.

## Features
- Real-time password strength checking
- Strength indicator bar
- Weak / Medium / Strong detection
- Password requirement validation
- Show/Hide password feature
- Strong password suggestions
- Modern purple-themed cybersecurity UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
The application analyzes the entered password and checks:
- Minimum length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

Based on these conditions, the password strength is displayed dynamically.

## Output
The tool classifies passwords as:
- Weak
- Medium
- Strong

and provides suggestions to improve password security.
